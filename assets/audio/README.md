# Almsth audio assets

Все WAV-файлы в этой папке процедурно сгенерированы внутри проекта. Сторонние записи,
семплы и лицензируемые аудиобиблиотеки не использовались.

Формат: mono PCM WAV, 22050 Hz, 16 bit. Фоновые петли содержат WAV `smpl` loop metadata.
Генератор использует фиксированное seed-значение и выдаёт одинаковые байты при повторном
запуске.

Команда регенерации из корня проекта:

```powershell
python tools/generate_audio_assets.py
```

Если системный Python отсутствует, можно передать любой совместимый Python 3 полным путём.
