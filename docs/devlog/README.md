# Almsth devlog drafts

The Russian files are the primary DTF-ready drafts. English files are separate adaptations rather than mixed bilingual posts.

## Publication order

1. `week-01-ru.md` — premise, core loop, procedural generation, and the first visual direction.
2. `week-02-ru.md` — death, secured progress, the camp, inventory, and body development without revealing the full progression chain.
3. `week-03-ru.md` — auto-exploration, hearing, active abilities, map scale, and a real testing failure caused by random floor geometry.

Each Russian draft is roughly 650–760 words and contains three selected illustrations, a short formal progress summary, a next-step section, and one player-facing question.

The posts reconstruct development thematically from the first three major repository stages. They intentionally group related work into notional “weeks” of one or two active development days instead of claiming a literal calendar chronology.

## Images

The Markdown paths point to the exact local source files selected for each post. DTF requires the images to be uploaded; the relative links are editorial references, not public URLs. The preferred cover is the first image in each article:

- week 1: the awakening illustration;
- week 2: the built camp;
- week 3: the hearing/noise screenshot.

English drafts use English UI captures where matching versions exist. Week 1 keeps the early Russian prototype capture because it represents the actual visual stage more accurately than the later English captures.
