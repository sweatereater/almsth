# Almsth Wiki viewer

Статическая локальная оболочка над `docs/wiki/*.md`. Она не содержит второй копии игровых таблиц: build читает Markdown и generated JSON, затем собирает `dist/`.

Из корня проекта самый короткий запуск:

```powershell
.\tools\start_wiki.ps1
```

Viewer будет доступен на `http://127.0.0.1:4173`. Сеть, API-ключи и внешнее хранилище не используются.

Скрипт находит Node.js из `PATH` либо bundled runtime приложения и перед запуском автоматически пересобирает `dist/` из текущих Markdown/generated-файлов. Устанавливать npm/pnpm-пакеты и вручную дублировать контент не нужно.
