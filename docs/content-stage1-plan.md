## Решения пользователя и явные рабочие трактовки

- E06: HP5/дальний урон2/точность4/уклонение0/обзор6/дальность5/души3,
  min_depth20. Подготовка **2 хода**, затем выстрел после повторной проверки цели/LOS,
  откат3, **1 ход неподвижности после выстрела**. Пунктир виден сразу при начале
  подготовки, только при текущей видимости врага; не раскрывает туман.
  Рабочий таймлайн: первое действие после выстрела — обязательный простой,
  второе/третье — можно преследовать, новую подготовку нельзя начинать;
  следующий цикл после истечения отката. Отмена подготовки занимает действие ИИ.
- E09: HP10/обычный урон2/точность4/уклонение0/обзор5/души5, min_depth15.
  Замах1 ход, сильный удар5 по исходной соседней клетке, откат6; мясо нет.
  Ранние пороги выбраны пользователем для демо. Биом Z03 не добавлять.
- Обычные параметры врагов масштабируются существующими формулами. Двойная атака
  использует обычный масштабированный урон; специальный удар кузнеца остаётся5.
- B05 «Мурал / Mural»: граффити победы над Минотавром. Первая победа даёт ровно1
  постоянный неразбираемый трофей «Хвост Минотавра», расходуемый только Муралом.
  Хранить историю первой победы/выдачи отдельно от временного этажа. Повторная
  победа, загрузка и повторный урон по мёртвому врагу не дают ещё хвост.
  До владения хвостом нет кнопки/описания/фокуса предложения. После постройки
  рисунок остаётся, хотя хвост потрачен. Цена: дерево12, камень20, ткань5,
  **сохранённые души60**, хвост1. Атомарная оплата; +1 постоянный уровень души один раз.
- M04: **HP и сытость восстанавливаются при входе в лагерь; все временные лагерные
  эффекты выдаются при выходе**. Право возникает только после настоящего возврата.
  Начало новой игры, загрузка, меню и повторный выход не дают нового права.
  Сохранять право, выбор котла и флаг снятого бонуса рюкзака. Лечение маны сохранить
  по существующим правилам, если оно не создаёт повторного HP/сытости.
  Рабочее правило: при возврате запомнить допустимые эффекты по настоящей форме
  и Желудку; покупка Желудка после возврата не выдаёт не заработанную Сытость.
- B02: постройка дерево6/камень8/ткань2; выбранная подготовка стоит1 еду при
  подтверждённом выходе и даёт +100 Сытости. Отмена и повторные клики не списывают еду.
- B03: постройка дерево8/ткань6, один уровень; +100 длительности Отдыха.
- I19: +200 к новым Сытости и Отдыху. Итоги без построек600/700, с ними700/800.
  Первое снятие **или замена** после выхода вычитает min(200, остаток) каждого
  получившего бонус статуса. Надевание обратно не возвращает, повторное снятие не
  вычитает снова. До выхода снятие просто исключает бонус из расчёта.
- M05: метки стака «Беречь / На разбор», снятие метки допускается. Массовый разбор
  исключает Беречь и связанные вещи; режим только На разбор. Рабочие безопасные
  правила: при слиянии Беречь приоритетно; На разбор + без метки = без метки;
  метка следует за экземпляром при экипировке/заточке/привязке и обратно.
  Одиночный разбор Беречь требует явного подтверждения; не расширять защиту от смерти.
- D02: участок8–16 клеток, приблизительно квадратный, допустима неровность границ
