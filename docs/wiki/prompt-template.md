# Шаблон промта для разработки

Статус: `implemented`

Перед задачей приложите [Текущий срез](current-snapshot.md) или скопируйте его кнопкой в локальном viewer. Для чисел и стабильных ID ссылайтесь на [сгенерированный справочник](generated/game-reference.md).

```text
Задача:
<одно наблюдаемое изменение>

Текущее поведение:
<что происходит сейчас; статус implemented/partial/placeholder/absent>

Желаемое поведение:
<что должен увидеть или сделать игрок>

Затрагиваемые ID:
<form_id, skill_id, ability_id, item_id, enemy_id, state fields>

Что не менять:
<баланс, соседние системы, UI, управление и т. п.>

Инварианты:
- Поведение после смерти:
- Поведение после безопасного возвращения:
- carried_souls / banked_souls / absorbed_souls:
- Совместимость старых сохранений:

Локализация:
- Новые/изменённые RU строки:
- Соответствующие EN строки:

Критерии приёмки:
1. <проверяемый результат>
2. <граничный случай>
3. <что должно остаться прежним>

Проверки:
- Узкий тест:
- Smoke test:
- Нужен ли soak (generation/progression/randomness/survival/long state):

Документация:
<какие страницы wiki и generated reference должны измениться>
```

## Короткий пример

```text
Задача: дать контрольному якорю новое действие.
Текущее поведение: checkpoint_floor сохраняется каждые 5 этажей, статус partial, эффекта нет.
Желаемое поведение: ...
Что не менять: верёвку и обычный старт с 99-го этажа.
После смерти: ...
Совместимость: старые сохранения без новых полей должны загрузиться.
Критерии: ...
```

Не подставляйте за многоточия догадки: если продуктового решения ещё нет, оставьте вопрос явным.
