# Almsth Wiki

Локальная developer-wiki текущего прототипа. Основной язык — русский; стабильные ID из кода и английские названия сохранены там, где они помогают формулировать задачи без двусмысленности.

Статус: `implemented`

## Как читать

- В Obsidian откройте папку `docs/wiki` как vault либо весь репозиторий и перейдите к этой странице.
- В локальном viewer выполните из корня проекта:

```powershell
.\tools\start_wiki.ps1
```

Затем откройте `http://127.0.0.1:4173`. Viewer работает без интернета, умеет искать по всем страницам, фильтровать статусы и копировать контекст для промта.

## Значения статусов

| Статус | Значение |
| --- | --- |
| `implemented` | Поведение реализовано и подтверждается текущим кодом или тестами. |
| `partial` | Есть состояние или интерфейс, но самостоятельный игровой эффект реализован не полностью. |
| `placeholder` | В интерфейсе зарезервировано пустое место без утверждённой механики. |
| `planned` | Намерение явно закреплено в текущем проекте, но адаптер или функция ещё не реализованы. |
| `absent` | Механики сейчас нет; это описание ограничения, а не обещание её добавить. |

## Источник истины и обновление

Точные таблицы реестров и runtime-констант создаются из `GameRules`, `SkillSystem`,
`StatusSystem`, `Loc`, `FloorGenerator` и `FixedFloor90`:
[generated/game-reference.md](generated/game-reference.md) и `game-reference.json`. Ручные
страницы объясняют поведение и могут повторять важные числа для связности текста.
Wiki-контракт проверяет их статусные строки, ссылки и anchors, а ключевые поведенческие
инварианты покрываются игровыми тестами; это не автоматическое доказательство каждого предложения.

После изменения игровых реестров:

```powershell
./.tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tools/generate_wiki.gd
./.tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tools/generate_wiki.gd -- --check
.\tools\start_wiki.ps1
```

`--check` ничего не перезаписывает и завершится ошибкой, если RU/EN ключи или ссылки между реестрами нарушены, generated-файлы устарели либо wiki-контракт нашёл сломанную ссылку, anchor или статусную строку. `start_wiki.ps1` сам пересобирает viewer из тех же Markdown-файлов. Ручные страницы генератор не изменяет.
