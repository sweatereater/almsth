# Противники

Статус: `implemented`

В текущем реестре 9 противников. Восемь участвуют в процедурных пулах, Минотавр
размещается только на фиксированном этаже 90.

| ID | Роль в текущем прототипе |
| --- | --- |
| `grave_rat` | Ближний мясной противник; присутствует с начала. |
| `blind_scavenger` | Медленный мясной падальщик; входит в пул с глубины 4. |
| `hollow_guard` | Ближний противник; входит в пул с глубины 6. |
| `arachnid` | Делает два независимых обычных броска; входит в пул с глубины 11. |
| `soul_leech` | Более сильный ближний противник; входит в пул с глубины 15. |
| `slag_smith` | Готовит удар по клетке один ход; входит в пул с глубины 15. |
| `skeletal_archer` | Дальнобойный противник с дальностью 5; входит в пул с глубины 6. |
| `bone_crossbowman` | Готовит дальний выстрел два хода; входит в пул с глубины 20. |
| `minotaur` | Босс фиксированной арены 90, мясной, использует способность `dash`. |

Базовые HP, урон, души, точность, уклонение, обзор и RU/EN названия: [generated/game-reference.md#противники](generated/game-reference.md#противники).

## Пулы обычных этажей

`depth = 100 - floor_number`

- глубина 0–3: только `grave_rat`;
- глубина 4–5: добавляется `blind_scavenger`;
- глубина 6–10: добавляются `hollow_guard` и `skeletal_archer`;
- глубина 11–14: добавляется `arachnid`;
- глубина 15–19: добавляются `soul_leech` и `slag_smith`;
- глубина 20+: добавляется `bone_crossbowman`.

На этажах 89–80 биом Ткацких склепов выбирает Арахнида с вероятностью 60%; оставшиеся
40% берутся из обычного пула без повторного веса Арахнида. Число врагов не меняется.

Число врагов в основном зале равно `min(12, 5 + floor(depth / 12))`.
Каждая из 2–3 закрытых комнат добавляет 2–3 врага из того же пула с теми же бонусами.

## Глубинное усиление

Для процедурно созданных врагов к базовым значениям прибавляется:

- HP: `floor(depth / 20)`;
- урон: `floor(depth / 35)`;
- точность: `floor(depth / 25)`;
- уклонение: `floor(depth / 30)`;
- награда душами: `floor(depth / 30)`.

Обзор не усиливается. Минотавр фиксированного этажа использует базовые значения реестра без этой формулы.

## Поведение

Противники имеют собственный радиус обзора и не видят сквозь стены и закрытые двери.
Первое зрительное обнаружение игрока устанавливает `has_seen_player` и пропускает ровно
одно действие врага (включая Минотавра). Пауза не повторяется после потери обзора.
Далее враги преследуют последнюю известную позицию, а `skeletal_archer` стреляет при
допустимой линии выстрела. Арахнид делает два независимых броска за действие с откатом 15.
Костяной арбалетчик готовится два хода, повторно проверяет цель/LOS, стреляет и один ход
восстанавливается; Шлаковый кузнец один ход замахивается по исходной соседней клетке,
после чего получает шесть ходов отката. Враги не открывают двери, но проходят открытые проёмы.
С навыком `ears` скрытые атаки оставляют временный обезличенный контакт, близкие враги
слышны в радиусе `effective player vision + 1` через стены. Обитатели ещё закрытых комнат
полностью исключены из слуха и вторичных целей рикошета до открытия двери.
Без `ears` слух отключён; сами атаки и урон работают обычно. После смерти Минотавра
открывается дверь к лестнице и двум сундукам.

Мясные противники (`grave_rat`, `blind_scavenger`, `minotaur`) дают одну единицу `food`
при убийстве.
